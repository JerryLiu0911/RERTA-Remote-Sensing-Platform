## 1. Prediction — honest out-of-sample R² (nested CV)  *(PROVISIONAL — pending full run)*

Source: `nested_cv_results.md`. `nested` = leakage-free (selection/PCA re-fit per fold); baseline = mean
predictor; n = plots.

| Target | Best honest nested R² | Model / feature set | Baseline R² | n |
|---|--:|---|--:|--:|
| average_canopy_openness | **≈ +0.15** | OLS, vi (also bands+vi +0.14) | −0.08 | 48 |
| average_seed_removed_proportion | ≤ 0 | all | −0.03 | 48 |
| Circle_change_mm | ≤ 0 | all | −0.12 | 32 |
| Harvesting_path_change_mm | ≤ 0 | all | −0.09 | 32 |
| Windrow_change_mm | ≤ 0 | all | −0.06 | 32 |
| average_change_mm | ≤ 0 | all | −0.12 | 32 |

Key statements (provisional):
- The report's RF R² = 0.36 for canopy openness **does not reproduce**; honest nested R² ≈ 0.04 (tuned
  RF) to 0.18 (OLS). The 0.36 came from a single small test split.
- Canopy openness is the **only** target clearing baseline, but it is a **terrain artefact, not proxy
  validation**: the `canopy_openness_DEM` proxy tracks terrain elevation (Pearson r ≈ −0.76 with mean
  DEM) far more than the field measurement (+0.50); controlling for terrain drops proxy↔field 0.50→0.22,
  for treatment 0.50→0.30; within-treatment r ≈ 0.28 (negative in one treatment). Confound path:
  `terrain ← (location of) treatment → canopy openness`. Treat as a terrain/treatment confound of an
  absolute-threshold DSM metric (see outline §4.1b/4.1d), which strengthens the negative.
- **OLS ≥ tuned RF** wherever it matters — model complexity did not help at n = 32–48.
- Leakage optimism (leaky − nested) is small/stable for OLS, large and sign-inconsistent (−0.20 to
  +0.24) for RF + selection.

## 2. Treatment discrimination — plot level (D2)  *(FINAL)*

Source: `plot_level_discrimination_results.md` (Kruskal–Wallis across treatments A–D, one value per plot,
Benjamini–Hochberg FDR). **20 of 39 metrics significant at FDR < 0.05; 11 structural/textural.**

| Metric | Type | η² | FDR p |
|---|---|--:|--:|
| range_GLI | spectral range | 0.65 | <0.001 |
| homogeneity_ReNDVI | textural | 0.46 | <0.001 |
| contrast_Clre | textural | 0.46 | <0.001 |
| homogeneity_Clre | textural | 0.46 | <0.001 |
| range_Clre | spectral range | 0.44 | <0.001 |
| energy_Clre | textural | 0.44 | <0.001 |
| contrast_ReNDVI | textural | 0.39 | 0.001 |
| range_ReNDVI | spectral range | 0.38 | 0.001 |
| mean_DEM | structural (terrain-confounded) | 0.37 | 0.001 |
| canopy_openness_DEM | structural (terrain-confounded) | 0.30 | 0.003 |

Key statements (final):
- Discrimination is **vegetation-driven, not terrain**: `mean_DEM` separates but is terrain-confounded,
  and critically `range_DEM` (η²=0.08, FDR=0.14) and `cv_DEM` (FDR=0.64) do **not** separate. Lean the
  structural claim on **texture + spectral range**.
- `homogeneity_GLI` does **not** survive (η²=0.01, FDR=0.40) — drop that specific report claim; use
  Clre/ReNDVI texture instead.
- η² interpretation: 0.01 small, 0.06 medium, 0.14 large (Cohen) — the top metrics are very large effects.
- Caveat to disclose: KW treats plots as independent; the design is nested (plots within
  transect/side/distance). Effects this large are unlikely to overturn under a mixed model, but state it.

## 3. Power / minimum detectable effect  *(FINAL)*

Source: `power_statement.md` (Fisher-z, 80% power, α = 0.05, two-sided).

| n | context | detectable r | detectable R² |
|--:|---|--:|--:|
| 48 | canopy openness, seed removal | 0.39 | 0.16 |
| 32 | erosion targets | 0.48 | 0.23 |
| 12 | within one treatment | 0.73 | 0.54 |

Ready-to-adapt statement is in `power_statement.md`. Core point: the study could detect only **strong**
associations; the bound is **optimistic** (multivariate/RF weaker; misalignment attenuates further), so
it excludes strong links *as expressed in these data* — not weak links, nor the underlying relationship.

## 4. Design / sample-size facts
- 4 treatments (A–D); ~12 plots per treatment.
- n = 48 plots for canopy openness & seed removal (all veg plots); n = 32 for erosion (BC + OPC only).
- Unit of analysis = vegetation plot (one value per plot), not pixel.
- UAV: July 2025; field data: 2017–2024 (variable per dataset — see temporal-gap table, TODO).
